# 静态图的证据与导出约定

Python后端沿用已保存的偏好。所有英文、数字和数学符号Times New Roman，中文SimSun；宽180 mm、最小字形5 pt，PDF/SVG可编辑，PNG300 dpi、TIFF600 dpi，无动画。

核心问题是无未来水位输入时新修正是否实际改善洪水演算。A图分别显示未知边界场景差异、同一验证事件配对的RMSE改变和非零修正压力试验，明确移植控制是假设；不能把alpha=0的退化结果隐去。B图显示全部20场出口涨幅、6场开发内验证的同事件误差变化，以及参考/预测长度。训练14／验证6按原49／21划分继承，不能称为封存测试。

主图采用定量网格，每个面板回答不同问题；多事件汇总的变动范围统一为事件间四分位距而非置信区间。逐场图册包含A全部21个主动态验证洪水和B全部20场，所有原始负流量保留。只因图册篇幅将场次分文件，不按精度筛图；计算失败列入失败表，不补造过程。

固定参数步长图保留失败。水面线差和几何附加体积单独评价，不能与互补潜在滞蓄混同。每个数值图回溯逐场表、预测文件与冻结清单。最终检查渲染、PDF实际字体/字形、图例冲突和远端阅读包版本。
